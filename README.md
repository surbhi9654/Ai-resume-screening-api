# AI Resume Screening API

An AI-powered Resume Screening API built with FastAPI. The application extracts relevant information from resumes and evaluates them against job requirements.

## Features

- Resume upload and processing
- Resume text extraction
- Candidate information extraction
- AI-powered resume analysis using Gemini API
- Resume screening based on job requirements
- FastAPI REST API
- Interactive Swagger API documentation

## Tech Stack

- Python
- FastAPI
- Gemini API
- SQLAlchemy
- PostgreSQL
- NLP
- Uvicorn
